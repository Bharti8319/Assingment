# Aidly — Onboarding Experience

A responsive Flutter onboarding module for **Aidly**, an all-in-one digital healthcare platform. Designed with smooth `GoRouter` slide transitions, custom curved navigation, and an interactive service showcase for ambulance booking, home care, pharmacy store, doctor appointments, lab tests, and health insurance.

## Features
- **Responsive UI:** Adaptive layout scaling across mobile screen sizes using custom `CustomClipper` curved navigation and soft blue gradient backgrounds.
- **Smooth Navigation:** Custom slide page transitions powered by `go_router` with timed auto-advance and manual page indicator controls.
- **Healthcare Service Grid:** Interactive 3×2 grid highlighting core healthcare services with centralized asset management (`AppAssets`).
- **Modular Project Structure:** Organized routing, constants, and barrel exports (`Directories.dart`) for clean scalability.
